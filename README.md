# 重要讲话与最新提法数据库 · 网站 Demo

一个纯静态、可离线打开的政策文件与重要论述检索网站。内容结构完全对应 `source/` 目录下的原始资料：
《重要讲话与最新提法数据库》各期 Word 文件、历届党和国家领导人论述汇总表、习近平总书记重要文章与青年寄语。

- **网站主目录**：`site/`（双击 `site/index.html` 即可浏览）
- **数据源目录**：`source/`（从原始资料复制而来，重跑脚本即可更新网站）
- **工具目录**：`tools/`（解析与生成脚本）

## 二、新增一期怎么做

这是本网站的设计重点：**丢文件即入库，不需要改任何代码**。

1. 把新一期的 Word 文件放进 `source/2.北大青年纵横/主文件/`，
   命名与现有文件保持一致，例如 `重要讲话与最新提法数据库-总第23期.docx`。
2. 在项目根目录依次执行：

```powershell
python tools\extract.py     # 解析 Word -> site/data/content.json，并打印解析自检表
python tools\build.py       # 生成 site/data/db.js 与全部页面
```

3. 刷新页面即可看到新的一期。

若领导人论述、重要文章、青年寄语有更新，按原文件名替换 `source/1.党和国家领导人关于共青团及青年工作重要论述/` 下的文件后，同样重跑这两条命令。

## 三、数据是怎么解析的

`tools/extract.py` 按源文件的固定版式解析，不需要手工录入：

| 源文件 | 版式 | 解析出的结构 |
| --- | --- | --- |
| `重要讲话与最新提法数据库-总第N期.docx` | 报头表格（日期+期号+概览）→ 章节（一、二…）→ 条目（标题：/发布时间：/发布来源：/原文链接：/关键词：/观点速览：）→ 页脚表格（审核/主编/编辑） | 每期一条记录 + 该期条目数组 |
| `3历届党和国家领导人关于共青团及青年工作重要论述.docx` | 5 列表格：领导人 / 时间 / 场合 / 性质 / 对应原句 | 42 条论述，自动向下填充合并单元格里的领导人名 |
| `1习近平总书记关于共青团与青年工作重要文章汇总.docx` | 封面 → 文章标题行 + 日期行 + 正文 | 12 篇文章全文 |
| `2习近平总书记对教育工作、青年群体的指示、寄语与回信.docx` | `一 寄语篇` → `一、谈理想` 等主题 → 语录 + `——出处` | 64 条寄语，按主题分组 |

解析脚本自带自检，会逐期打印条目数与异常提示，并输出一份**数据质量报告**（见下）。

## 四、源文件里发现的数据问题（19 处，需人工确认）

解析过程中发现源 Word 文件本身存在期号不一致，脚本**没有做任何自动改写**，而是如实记录并在页面上标注。
按严重程度分两级，避免所有卡片都挂警告：

**需要处理（5 处，页面上打「期号待核」标记）**

1. **报头期号是占位符** —— 总第 3、4、5 期的报头写作「总第X期」（另外总第 4 期报头日期也是「2026年X月X日」占位符），脚本改用文件名期号与条目日期。
2. **期号重复** —— 总第 17 期有两个文件（报头分别为 8月26日、8月28日）。
3. **期号跳号** —— 数据源中没有总第 6、18、20 期。

**仅登记、不影响使用（14 处，页面显示淡蓝色「源文件期号差异」小标）**

4. **报头期号与文件名期号相差 1** —— 共 16 期中的 14 期（如文件名为「总第6期」，报头写「总第7期」）。
   这属于源文件的系统性命名习惯，页面上以报头期号为准（它是文章正文里引用的期号），
   鼠标悬停可看到具体差异说明。

网站的「关于本库 → 数据质量核对」页会完整列出这 19 处。
**建议在源 Word 文件里确认期号后重跑脚本**，这些问题会自动消失。

## 六、自检

```powershell
python tools\extract.py --check   # 只做解析自检，不写文件
python tools\build.py --check     # 只校验数据，不生成页面
node   tools\verify.js            # 站点渲染自检
```

`tools/verify.js` 用一个内置的最小 DOM 实现把 `assets/app.js` 真正执行一遍，检查：

- 每个页面渲染时 JS 是否抛异常；
- 动态容器是否被正确填充（期次卡片、条目卡、表格行、检索命中数）；
- 带参数的页面（`issue.html?no=13`、`?no=999`、`search.html?q=青年`、`database.html?cat=…`）是否行为正确；
- 页面文本里是否残留 `undefined` / `NaN` / 未替换占位符；
- 数据完整性：期次数量、条目数量、必填字段、领导人论述行数、文章篇数。

## 七、技术说明

- **零依赖**：HTML + CSS + 原生 JavaScript，不使用任何框架、构建工具或 CDN。
- **可离线**：数据内嵌在 `site/data/db.js`（`window.DSH_DB`），
  因此双击 `index.html` 即可正常浏览，不受 `file://` 跨域限制。
- **零外链**：不引用任何外部字体、图片或脚本；图标与 favicon 均为内联 SVG。
- **响应式**：桌面 / 平板 / 手机三档断点，移动端折叠导航、卡片单列。
- **可访问性**：语义标签、跳过导航链接、键盘焦点样式、表格表头作用域、
  `prefers-reduced-motion` 支持，以及打印样式。
