# 数据库收录规则（相关性白名单）
#
# 目的
#   把《重要讲话与最新提法数据库》里与「青年和共青团工作」无关的时政、政策条目剔除，
#   只保留与青年、共青团、团学工作、青少年成长发展相关的条目。
#
# 为什么用白名单而不是黑名单
#   黑名单要写 30 多条“删除”规则，漏写一条就会把无关内容悄悄放进来；
#   白名单只声明“收录什么”，漏写只会少收一条，并且脚本会报错提醒。
#
# 匹配方式
#   对条目标题做“包含”匹配（不区分大小写）。写得越短，匹配越宽。
#   支持以 - 开头的行表示“即使命中白名单也排除”（例外项）。
#
# 用法
#   python tools\extract.py     # 会打印每期收录/排除结果
#   python tools\build.py       # 重新生成网站
#
# 想多收一些内容？在 [include] 下加关键词即可，例如加一行：
#   青年
# 则凡标题含“青年”的条目都会被收录。

[include]
# —— 与共青团、青年工作直接相关 ——
阿东
共青团
团中央
青少年
青年

# —— 青年发展相关的规划、教育与思政工作 ——
青年发展
中长期青年发展规划
立德树人
思想政治工作
思政

[exclude]
# —— 例外：命中上面关键词但不属青年工作的条目（手工排除）——
# 留空即可

[note]
# 现有 20 期共 36 条内容，按上述规则筛完后，与青年和共青团工作相关的条目很少
# （源文件本身是泛时政汇编，并非专门面向青年工作）。
# 因此网站数据库栏目会显得比之前“瘦”，这是符合“删去与共青团无关内容”要求的正常结果。
# 若希望内容更丰富，可放宽 [include]（例如加入“教育”“高校”“学生”）。
